
# Система регистрации и обработки претензий по качеству продукции

Веб-приложение для регистрации, просмотра и обработки претензий по качеству продукции. Система позволяет пользователям подавать претензии, а сотрудникам организации — отслеживать их статусы и управлять процессом рассмотрения.

## API

Приложение предоставляет REST API для работы с заявками на гарантийное обслуживание.

### Основные эндпоинты

- `GET /api/claims` — получить список всех заявок.
- `GET /api/claims/{id}` — получить информацию о конкретной заявке по её ID.
- `POST /api/claims` — создать новую заявку.
- `PUT /api/claims/{id}` — обновить существующую заявку.
- `DELETE /api/claims/{id}` — удалить заявку.

### Формат данных

Все запросы и ответы используют формат JSON.
