
# Система регистрации и обработки претензий по качеству продукции

Веб-приложение для регистрации, просмотра и обработки претензий по качеству продукции. Система позволяет пользователям подавать претензии, а сотрудникам организации — отслеживать их статусы и управлять процессом рассмотрения.

## Предметная область

- **Основная сущность:** претензия по качеству продукции.
- **Пользователи:** покупатели, которые регистрируют претензии и отслеживают их статус; специалисты по работе с претензиями, которые рассматривают обращения и управляют их обработкой.
- **Планируемые эндпоинты:**
  - `POST /claims` — создание новой претензии.
  - `GET /claims` — получение списка претензий.
  - `GET /claims/{id}` — получение информации о конкретной претензии.
  - `PUT /claims/{id}` — изменение информации о претензии.
  - `DELETE /claims/{id}` — удаление претензии.
